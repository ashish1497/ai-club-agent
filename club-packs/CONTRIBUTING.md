# Contributing a pack

**What:** How to add a domain pack to the library.
**How:** Copy `club-agent/templates/domain-pack.md` to `packs/<field>.md`, fill the 7 sections, and commit.
**Objective:** Packs stay comparable and easy for the agent to reuse.

1. Name the file in kebab-case after the field, for example `packs/retail-media.md`.
2. Keep exactly the 7 template headings.
3. Put links to sources and feeds, not summaries of paywalled content.
4. Never include personal data.
5. Your agent's own `domains/<field>.md` is a good starting point once its sources are verified.
6. There is no review gate. Agents re-verify everything, so mistakes cost the next reader time, not safety.
