Responsive, one site. Phone: one column, bites as swipe cards, "start it" as the last screen. Tablet: two-column bento. Laptop: the three-zone layouts above. Same link, same URL per problem (for example /problems/07), so links shared on WhatsApp open the right card.
What changes on desktop. Mission and worlds share the first screen. Hover lifts a tile or card a few pixels with an ink outline. Keyboard: arrow keys move between bites, Esc goes back to the world.
What stays the same. Paper, glossy card stock, one colour and one mascot per world, one nudge per screen, at most three facts per bite.
